# 🚚 Диспетчер Pro

Система управления заказами с диспетчеризацией в реальном времени.

## 📋 Возможности

- 👥 Роли: Руководитель, Диспетчер, Менеджер, Клиент
- 📦 Управление заказами (добавление, редактирование, удаление)
- 🔄 История изменений с именем автора
- 📊 Статистика по диспетчерам
- 🔐 Авторизация по паролю
- ☁️ Синхронизация через Google Sheets

## 🚀 Быстрый старт

### Требования
- Google аккаунт
- Браузер Chrome/Firefox/Safari/Edge

### Установка

1. **Скопируй Google Sheet шаблон:**
   - Создай свою Google Sheets таблицу
   - Добавь три листа: Заказы, Пользователи, История
   - Скопируй ID из URL

2. **Настрой Apps Script:**
   - В таблице: Расширения → Apps Script
   - Вставь код из `apps-script-code.txt`
   - Сохрани (Ctrl+S)
   - Нажми "Развернуть" → "Новое развертывание"
   - Выбери "Веб-приложение", "Все", нажми "Развернуть"
   - Скопируй URL

3. **Открой приложение:**
   - Скачай `dispatcher-v4.html`
   - Открой в браузере
   - Войди: Руководитель / admin123

## 📖 Инструкция

### 👑 Руководитель может:
- Добавлять, редактировать, удалять заказы
- Управлять пользователями
- Смотреть статистику и историю

### 👨‍💼 Диспетчер может:
- Добавлять и редактировать заказы
- Смотреть историю своих действий
- Видеть список команды

### 📋 Менеджер может:
- Смотреть все заказы
- Смотреть статистику
- Видеть список команды

### 👤 Клиент может:
- Вводить номер заказа
- Смотреть статус своего заказа

## 🛠️ Технологии

- HTML5 / CSS3 / JavaScript (ванильный, без фреймворков)
- Google Sheets API (через Apps Script)
- Локальное хранилище браузера

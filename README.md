# 🚚 Диспетчер Pro

![GitHub](https://img.shields.io/badge/GitHub-Dispatcher%20Pro-blue?style=flat-square&logo=github)
![License](https://img.shields.io/badge/License-MIT-green?style=flat-square)

Современная система управления заказами и диспетчеризации в реальном времени. Работает как веб-приложение, но устанавливается как обычное приложение на рабочий стол и телефон.

## ✨ Возможности

### 👥 Разные роли с разными правами

- **👑 Руководитель** — полный доступ: управление заказами, пользователями, статистика
- **👨‍💼 Диспетчер** (до 5+) — добавление и редактирование заказов
- **📋 Менеджер** — просмотр всех заказов и статистика
- **👤 Клиент** — просмотр только своих заказов

### 📦 Управление заказами

- ➕ Добавление новых заказов
- ✏️ Редактирование (кто и когда менял)
- 🗑️ Удаление заказов
- 🔄 Отслеживание статуса: новый → в пути → доставлен / ошибка
- 📍 Маршруты (погрузка → выгрузка)
- 🕐 Время выезда и доставки
- 💬 Заметки к каждому заказу

### 📊 Статистика и аналитика

- Общее количество заказов
- Разбор по статусам
- Производительность по диспетчерам
- 📜 История всех изменений (кто, когда, что менял)

### 🔐 Безопасность и авторизация

- Вход по логину/паролю
- Разные пароли для разных пользователей
- История действий каждого пользователя
- Логирование всех изменений

### ☁️ Облачное хранилище

- Синхронизация через Google Sheets (бесплатно)
- Доступно с любого устройства
- Реальная синхронизация между пользователями

### 📱 PWA (Progressive Web App)

- Установка как приложение на рабочий стол / телефон
- Работает без интернета (кеширование)
- Быстрое открытие (как native приложение)
- iOS и Android

## 🚀 Быстрый старт

### 1️⃣ Подготовка Google Sheets

1. Создай свою Google Sheets таблицу
2. Создай три листа:
   - **Заказы** — с заголовками: Номер заказа, Маршрут, ФИО клиента, Контакт, Статус, Время выезда, Время доставки, Заметки, Кто добавил, Дата добавления, Telegram клиента
   - **Пользователи** — с заголовками: Имя, Роль, Пароль, Telegram_ID, Активен
   - **История** — с заголовками: Дата, Пользователь, Роль, Номер заказа, Действие, Детали

3. Скопируй **ID таблицы** из URL: `https://docs.google.com/spreadsheets/d/{ID}/edit`

### 2️⃣ Настройка Google Apps Script

1. Открой свою Google Sheet
2. Нажми **Расширения** → **Apps Script**
3. Удали весь текст и вставь код из файла `apps-script-code.txt`
4. Нажми **Ctrl+S** (сохрани)
5. В редакторе выбери функцию `setup` и нажми «Выполнить»
6. Разреши доступ к Google Sheets (разовый запрос)
7. Нажми **«Развернуть»** → **«Новое развертывание»**
8. Выбери **«Веб-приложение»** и нажми **«Развернуть»**
9. Скопируй **URL веб-приложения** (заканчивается на `/exec`)

### 3️⃣ Скачай приложение

Скачай 3 файла:
- `dispatcher-v4.html` — само приложение
- `manifest.json` — конфигурация
- `service-worker.js` — кеширование

Положи их в одну папку.

### 4️⃣ Первый запуск

1. Открой `dispatcher-v4.html` в браузере
2. Войди с тестовыми учётными данными:

| Логин | Пароль | Роль |
|-------|--------|------|
| Руководитель | admin123 | 👑 Администратор |
| Диспетчер1 | disp111 | 👨‍💼 Диспетчер |
| Менеджер1 | mngr111 | 📋 Менеджер |
| Клиент | client123 | 👤 Клиент |

3. Нажми меню браузера → **«Установить приложение»**

## 🎯 Примеры использования

### Добавить заказ (Диспетчер)
1. Вкладка **📋 Заказы**
2. Заполнить форму слева
3. Нажать **➕ Добавить заказ**
4. Заказ появится в таблице и синхронизируется со всеми

4. Нажать **💾 Сохранить**

1. Вкладка **📊 Статистика**
2. Общее количество, разбор по статусам, по диспетчерам

## 🐛 Решение проблем

### Заказы не синхронизируются
- Проверь интернет
- Убедись что скопировал правильный URL Google Apps Script
- Открой консоль браузера (F12) и посмотри на ошибки

### Не входит в приложение
- Логин и пароль должны совпадать точно (с пробелами и регистром)
- Учётная запись должна быть активна (колонка "Активен" = "да")

### Приложение медленное
- Это PWA, первый запуск кеширует файлы — потом быстрее
- Проверь интернет — Google Apps Script требует соединения

## 📦 Развёртывание

### На GitHub Pages (бесплатно)

1. Создай репозиторий на GitHub
2. Загрузи 3 файла (dispatcher-v4.html, manifest.json, service-worker.js)
3. Перейди в Settings → Pages
4. Выбери ветку main → root → Save
5. Через 1-2 минуты сайт будет доступен по `https://твой-логин.github.io/dispatcher-pro/`

### На собственный сервер

1. Загрузи 3 файла на сервер
2. Убедись что используется HTTPS (обязательно для PWA)
3. Открой `dispatcher-v4.html` в браузере
